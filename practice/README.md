  - 1(16)② 五角形：写真の5つの角（85°, 60°, 115°, 70°, <i>x</i>）を素直に内角と

    図が凹んでいる可能性がある。位置だけ原本どおりに並べてある。
  - 1(16)③ ○印の付き方と <i>x</i> の位置。写真では判別しづらいので、
    大きい三角形の頂角92°／内部の点126°／底角に○印、という構成で描いた。
  - 1(17) 6つの寸法は「底辺6cm・軸まで2cm・上辺4cm・左上の段差2cm×2cm・左辺6cm」
    と解釈した。

### 別版（Codex 生成）から直したところ

原本の写真と1問ずつ突き合わせて直した。

| 箇所 | 別版 | 原本（この複刻） |
| --- | --- | --- |
| 1(9)(10) | 「を計算しなさい」 | 原本は「を<b>計算をしなさい</b>」（原本のままにした） |
| 1(10) | √27 + 3√3 | √27 + 3/√3（答 4√3） |
| 1(18) | 「例えば…」が枠の外 | 「例えば…」は&lt;操作&gt;の枠の中 |
| 1(18)② | 正三角形になる確率 | **二等辺三角形**になる確率 |
| 2(1) | ℓ と m の間に頂点がある折れ線 | 30° と <i>x</i> は ℓ 上の同じ頂点に並ぶ（∠x＝57°−30°） |
| 2(2) | 底角に印が2つずつ（二等分） | 底角は**3等分**（印3つずつ）。3(●+○)＝132 で ∠x＝48° |
| 2(3) | 小問が①② | 原本は 1 / 2。証明の最終行も原本のまま △AED≡△CFD |
| 3 | 「mの値を求めなさい」＋方眼つき | 「<i>m</i> にあてはまる数を求めなさい」＋方眼なしの図 |
| 4 図1 | 左そろえの階段形 | **左右対称のピラミッド形**、段の目安線と「◯段」つきの枠 |
| 4(3) | 「18枚ずつ3段…」と要約されて意味が通らない | 花子さんの文章をそのまま収録。図2は3段×6枚の**平行四辺形**（ひっくり返した図形を組み合わせた形） |
| 4(4) | 「nを使った式で表しなさい」 | 「<i>n</i>番目の図形では何cmであるかを求めなさい」 |
| 氏名欄 | 生徒名が入っていた | 空欄（個人情報は載せない） |

2(2)の3等分は、原本の余白にある解答者の計算（2x+2y=88 → x+y=44 → ×3＝132 → 180−132）から
確定した。底角を二等分と読むと ∠x=4° になってしまうので、印は3つずつが正しい。

### 図の検算

- 大問3：A(−4,2) B(8,8) C(2,9) D(−2,7) の面積は32。直線 y=mx は辺AB・CD と交わり、
  m=13/2 のとき切り取られる側の面積がちょうど16になることを確認した（座標は正しく読めている）。
- 大問4：n番目は 一番下の段 2n−1 枚、周の長さ 6n−2 cm、総数 n²枚、境目の長さ 2n²−3n+1 cm。
  n=3 で境目10cm、n=5 で周28cm となり、問題文の数値と一致する。

  矛盾しないことを確認してある。
- 2(1) の角の弧の位置。30° と <i>x</i> が ℓ 上の同じ頂点に並ぶ形として作図した。
