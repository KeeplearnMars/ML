## 作り方のメモ

- 本文・小問番号・チェックボックス・解答欄・ステップ表示・ノンブルまで再現。
- 図はすべてインライン SVG。折り返し図形は「折り目に関する対称移動」、

  （236＋21×3.14 に対して数値解 302.1）。

## 実力テストの複刻について

- 手書きの解答は写していない。氏名欄も空欄のまま。
- 図（五角柱・平行線と角・多角形・回転体・箱ひげ図・座標平面・平行四辺形）は
  すべてインライン SVG で描き起こし、表（度数分布表・3段のマス目）は HTML の表。
- 原本の写真から読み取れなかった箇所は下記のとおり。使う前に確認してほしい。
  - 1(16)② 五角形：写真の5つの角（85°, 60°, 115°, 70°, <i>x</i>）を素直に内角と
    すると和が540°にならない（85+60+115+70=330 → x=210°）。どれかが外角か、
    図が凹んでいる可能性がある。位置だけ原本どおりに並べてある。
  - 1(16)③ ○印の付き方と <i>x</i> の位置。写真では判別しづらいので、
    大きい三角形の頂角92°／内部の点126°／底角に○印、という構成で描いた。
  - 1(17) 6つの寸法は「底辺6cm・軸まで2cm・上辺4cm・左上の段差2cm×2cm・左辺6cm」
    と解釈した。

## 類題演習（test-drill-r8）

実力テスト①の次の5題を取り上げ、原題と同じ型の類題を3問ずつ作った（計20問）。

| 番号 | 題材 | もとの問題 |
| --- | --- | --- |
| 1 | 多項式÷単項式 | 1(3) |
| 2 | 因数分解（共通部分のおきかえ） | 1(6) |
| 3 | 2組の連立方程式の解が一致する条件 | 1(9) |
| 4 | 確率（もどす／もどさない） | 1(13) |
| 5 | 回転体の表面積 | 1(17) |

数値は答えが整数・既約分数・「□×3.14」になるように選んである。
連立方程式は先に (x, y) と a, b を決めてから右辺を逆算し、
回転体は多角形の頂点から側面積・円環の面積を機械的に足し上げて検算した
（原題272π＝854.08cm²、類題は98π／114π／108π）。
