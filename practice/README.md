## 作り方のメモ

- 本文・小問番号・チェックボックス・解答欄・ステップ表示・ノンブルまで再現。
- 図はすべてインライン SVG。折り返し図形は「折り目に関する対称移動」、
  回転図形は「中心のまわりの回転」を実際に計算した座標で作図しているので、
  角度や重なりが図として正しくなっている。
- へこみのある図形（L字）を円が転がる問題は、面積の式を数値積分で検算した
  （236＋21×3.14 に対して数値解 302.1）。
